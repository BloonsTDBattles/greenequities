# Green Equities Research

A comprehensive website dedicated to making sustainable investing accessible for everyone through education, tools, and research.

## Features

- **Educational Content**: Articles and guides on ESG investing, climate risk, and sustainable finance
- **Stock Database**: Curated list of 72+ sustainable stocks across 10 categories
- **Portfolio Greenifier**: Interactive tool to analyze and optimize portfolio ESG performance
- **ESG Basics**: Foundational knowledge about sustainable investing principles
- **Responsive Design**: Beautiful gradient-themed design that works on all devices

## Structure

```
.
├── index.html              # Homepage
├── articles.html           # Articles listing
├── esg-basics.html        # ESG fundamentals
├── stocks-list.html       # Sustainable stocks database
├── about.html             # About page
├── styles.css             # Main stylesheet
├── main.js                # JavaScript functionality
├── articles/              # Individual article pages
├── basics/                # ESG basics article pages
└── tools/                 # Interactive tools
    └── portfolio-greenifier.html
```

## Local Development

1. Clone the repository
2. Open any HTML file in a browser, or use a local server:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit http://localhost:8000

## Technologies Used

- HTML5
- CSS3 (with gradient backgrounds and responsive design)
- Vanilla JavaScript
- Chart.js (for portfolio visualization)
